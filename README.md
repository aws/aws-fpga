# AWS EC2 FPGA Development Kit

## F2

For [AWS EC2 F2 instance](https://aws.amazon.com/ec2/instance-types/f2) development, please use the latest [AWS FPGA Developer Kit](https://github.com/aws/aws-fpga/tree/f2).

## F1

[AWS EC2 F1 instances](https://aws.amazon.com/about-aws/whats-new/2017/04/amazon-ec2-f1-instances-customizable-fpgas-for-hardware-acceleration-are-now-generally-available) reached end of life on December 20, 2025. Please migrate to F2 instances for continued FPGA acceleration support.
